🎯 My Design Process

My design workflow focuses on the following stages:

Research — Understand the project, target audience, and user requirements.

Wireframing — Plan the structure and layout of each screen.

UI Design — Apply typography, colors, spacing, and visual elements.

Prototyping — Connect screens and create interactive user flows.

Testing & Refinement — Review usability and improve the design.

Presentation — Organize and showcase the final design.
